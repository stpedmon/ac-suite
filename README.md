# AC Asia Carrocería — Suite de Gestión

PWA interna de gestión (inventario, bodega, recibos, seguimiento, CRM) para AC Asia Carrocería.
Se publica en Netlify (suite.asiacarroceria.com) por despliegue continuo desde este repo.

- `index.html` — app completa (single-file PWA)
- `sw.js` — service worker (caché)
- `manifest.webmanifest` — manifest PWA
- íconos e imágenes de correo
